### 💰 FintraX — Gestión Financiera con IA

Plataforma web para la gestión de finanzas personales, desarrollada con una arquitectura Full Stack.

**Stack:** React · Node.js · Express · PostgreSQL · OpenAI API

* Gestión de ingresos, gastos y categorías.
* Dashboard con análisis financieros.
* Metas de ahorro y educación financiera.
* Chatbot IA para asistencia y automatización.
* Autenticación y comunicación mediante APIs REST.
* Desarrollo colaborativo utilizando Git, GitHub y Scrum.

---

### 🦴 SpineHero — Postura Inteligente con IA

Aplicación web desarrollada durante una hackathon de CódigoFacilito + AWS + Kiro AI.

**Stack:** React · TypeScript · MediaPipe · Web Workers · AWS Amplify · DynamoDB

* Análisis de postura utilizando la cámara del dispositivo.
* Procesamiento local mediante MediaPipe.
* Sistema de gamificación con mascota pixel-art.
* Arquitectura orientada a una experiencia interactiva y educativa.

---

### 🛒 Tienda Electrónica — Sistema de Gestión

Aplicación de escritorio desarrollada en Java para administrar operaciones de una tienda.

**Stack:** Java · MySQL

* Gestión de productos e inventario.
* Registro de ventas.
* Gestión de usuarios.
* Operaciones CRUD.
* Arquitectura MVC.
* Control de stock y lógica de negocio.

---

### 🎮 ChronoBreak — Videojuego 2D

Videojuego de plataformas desarrollado individualmente.

**Stack:** Java · Android Studio · libGDX

* Sistema de físicas y colisiones.
* Enemigos y niveles.
* Animaciones.
* Interfaz gráfica.
* Gestión de recursos.
* Desarrollo completo desde la planificación hasta la implementación.
